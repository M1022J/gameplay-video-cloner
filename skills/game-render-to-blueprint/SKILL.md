# 效果图即施工图（Game Render to Blueprint）

复刻 UI 时，**效果图是施工图，不是风格参考**。1:1 还原是按图施工出来的，不是靠流式布局一点点凑出来的。

来源：《变废为宝》（竖屏垃圾桶寻宝）2026-11-07 复盘定版——远端实现用本法一次对齐；旧法（流式布局 + 公式参数追赶效果图）连追五轮未收敛。同日按用户令融合三项外部开源方法（分块还原、层级树拆解、反廉价感约束），出处见文末「外部方法来源」，仓内登记见 gameplay-video-cloner 的 SOURCES.md #44–#46。

## 流程

1. **先量测，后开发**：开发前先产出分析文档（如 `docs/ui-analysis.md`），逐页逐元素记录在原图上的坐标、尺寸、颜色、边框与内缩（原图分辨率即参考坐标系，如 1152×2048）。图上没有的东西不编造。
2. **坐标摆位**：建参考坐标视图层（如 `reference_view.lua`），每个元素按量测坐标绝对定位，整幅按参考分辨率等比缩放落屏。不用流式布局/内容撑高/百分比公式去「凑近」效果图。
3. **组件离线预成型**：纸面、按钮（含常态/按下/禁用三态）、缎带、徽章等组件，先在图上裁好成型为成品素材再进游戏；运行时**不做九宫格切片**，不与边厚、漏角、DPR 缠斗。
4. **内缩按量测值**：棋盘、面板等容器的边框内缩直接取量测数（如棋盘内缩 14.5%→5.5% 的教训：公式默认值会吃掉格面），不凭手感设。
5. **对图验收**：引擎内截图与效果图逐元素对照（坐标/尺寸/颜色/边框/内缩逐项打勾），差一项修一项；没亲眼对过图不许下「一样」的结论。

## 硬规矩

- **旧裁决与原图冲突先上报**：已定的行为/版式口径（如「点卡即领」「弹窗按内容定高」）与效果图原图打架时，把冲突摆给用户裁，不许默默守旧、也不许默默推翻。
- **无专属效果图的页面标「风格推及」**：只能按已有页面的风格语言（纸面卡、描边、色板）推及，并在分析文档里写明标准来源；不许假装有图、更不许虚构图上没有的元素。
- **三态齐全**：可点组件的常态/按下/禁用三态都要离线成型，缺态不许用运行时变色凑。
- **等比缩放单源**：全页共用一套参考坐标→屏幕的缩放与触点映射，禁止逐元素各算各的。

## 反例（勿重蹈）

- 把效果图当风格参考，用流式布局引擎凑版式，再靠预览截图逐轮往回追——每轮都差一点，永不收敛。
- 在九宫格切片上死磕参数（查格式、裁角、加内边距、回退），而不肯把组件改成离线成型。
- 守着旧裁决跟原图打架，既不推翻也不上报。

## 融合方法一：分块还原（源自 screenshot-to-code）

整页一次生成必糊，改按块施工：

- **先分语义块**：量测阶段就把效果图切成语义块（顶栏、主面板、棋盘、底部条、弹窗各为一块），每块单独记录坐标、内部元素与样式，施工与验收都以块为单位——哪块不对修哪块，不整页返工。
- **生成→截图→对照→修块，迭代收敛**：每块落地后立刻在引擎里截图与原图该块并排对照，差异逐项销账后再进下一块；不许全页做完才第一次看图。
- **原图素材能提取就不重画**：图上的图标、徽章、装饰件优先从原图裁取复用（离线预成型正是这条的落地），重画只用于原图取不到的件，且须单独过对图验收。

## 融合方法二：层级树拆解（源自 Design2Code / UI2Code）

坐标之外再补一棵树，管嵌套关系：

- **先拆节点层级树**：把每页拆成容器嵌套树（页→区块→组件→元素），逐节点记父子关系、对齐约束（同行基线、等距、居中轴）与层叠顺序；分析文档里坐标表与层级树并存——坐标管「在哪」，树管「谁包谁、谁压谁」。
- **文字先行提取**：全部文字元素先单独提取成表（内容、字号、颜色、位置），再摆非文字件；文字是位置与层级最容易错位的一类，先钉死。
- **自修正回路**：渲染结果与原图做块级比对（块匹配/文字/位置/颜色四维，Design2Code 的评测口径），按差异清单逐块修订；修订只动出差异的块，不全页重排。

## 融合方法三：反廉价感视觉约束（源自 Anthropic frontend-design）

有定版效果图时，效果图永远压过本节——本节管的是没有图的空隙处（风格推及页、过渡元素、文案）不许掉进 AI 默认模板感：

- **警惕默认脸**：奶油底+高对比衬线+陶土色点缀、近黑底+酸绿/朱红单点缀、报纸式细线零圆角、SaaS 卡片套件（等大圆角卡+同一团灰影+渐变洗色）、全大写眉题标签、「A · B · C」中点串、等宽字体小数据标签、按钮尾巴挂「→」——这些是默认而非选择，推及页里出现即返工。
- **个性靠主体长出来**：推及页的字体、色板、描边语言必须从本游戏已有定版页与题材里长（纸面、描边、色板同源），不许另起一套「通用好看」。
- **大胆只花在一处**：一页只留一个记忆点，其余安静克制；交付前自审一遍，摘掉一件多余装饰。
- **文案同规**：按钮名=动作本身且全流程同名（如「领取」点了就回「已领取」），句子式大小写、主动语态、不用系统黑话；错误与空状态给方向，不卖萌不道歉。
