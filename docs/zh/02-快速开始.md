# 02 · 快速开始

## 环境要求

- Python 3.10+，并安装依赖：`pip install -r requirements.txt`（Pillow、numpy）
- 系统工具 `ffmpeg` / `ffprobe`（视频抽帧与遥测必须）
- 可选：Node.js（部分上游 skill 的工具链才需要，核心脚本不用）

## 四步跑通

```bash
# 1) 视频遥测：抽 16 帧、拼接触表、HUD 方差图、主色板 → telemetry.json
python3 skill/scripts/analyze_gameplay_video.py <video.mp4> ./video_analysis --frames 16

# 2) 引擎路由：判断该用什么引擎/骨骼方案/品类基线
python3 skill/scripts/detect_engine_router.py --workspace . --prompt "<复刻需求一句话>"

# 3) 初始化蜂群：5 个子 Agent 的任务包 + 恢复台账 + DAG 任务板
python3 skill/scripts/orchestrate_subagents.py --project-dir ./subagent_workspace --game-title "<游戏名>"
python3 skill/scripts/swarm_task_board.py --board ./subagent_workspace/swarm_board.json init

# 4) 交付验收：3 点抽查（范围/契约/零占位符）+ 架构 8 项门禁
python3 skill/scripts/merge_subagent_modules.py <game.html>
python3 skill/scripts/validate_architecture.py <game.html>
```

## 怎么喂给 AI Agent

把仓库根目录的 `SKILL.md` 交给你的 Agent 环境（Claude Code / Cursor / Codex 等均可），
然后给它一段 gameplay 视频并说「按这个 skill 复刻」。Agent 会按 `SKILL.md` 的三轮流程执行，
需要查细节时读 `skill/references/`、`HANDBOOK.md` 与 `upstream/` 里的上游原文。
