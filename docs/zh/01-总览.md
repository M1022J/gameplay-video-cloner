# 01 · 总览

## 这是什么

Gameplay Video Cloner 是一套「看游戏视频直接复刻游戏」的 AI Agent 技能（Skill）：
输入一段 gameplay 视频、录屏、GIF 或视频链接，输出一个可玩的 1:1 复刻游戏
（HTML5 Canvas / Phaser / Three.js 等）。

它不是单提示词生成，而是 **主控 Agent（Lead）+ 并行子 Agent 蜂群（Swarm）** 的工程化流水线：
先从视频里量出事实（画幅、色板、HUD 位置、场景切换点），再把物理、骨骼动画、HUD/音频
拆给互不干扰的专科子 Agent 并行实现，最后过两阶段审查和架构门禁才交付。

## 本仓库的来历

原始 skill 包（zip）正文只有摘要：18 篇参考手册每篇只有几百字节，实质内容散落在它引用的
14 个开源仓库里。本仓库把这 14 个来源**全部下载并按引用范围整合**进来，与 skill 本体、
单文件手册（`HANDBOOK.md`）合成为一个打开即用的项目。来源与取舍见 `SOURCES.md`。

## 适合什么场景

- 复刻/仿制一款小游戏的玩法原型（合成消除、幸存者、平台跳跃、跑酷、塔防等）
- 从录屏反推数值与节奏：速度、重力、冷却、波次、分数曲线
- 给已有角色做 2D 骨骼绑定（Spine/Rive 思路）或 3D 程序化骨骼动画
- 多 Agent 协作开发游戏的任务拆分、契约与验收范式

## 不做什么

- 不还原原游戏的美术资产与代码（复刻的是玩法与表现规律，素材靠程序化绘制/生成）
- 视频里没展示的规则一律标「未知」，不臆造——这是本工作流的证据纪律
