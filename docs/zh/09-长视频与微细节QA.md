# 09 · 长视频、亚像素微差与微细节 QA（第四版增补）

## 要解决的三个盲区
1. **长视频看不完**：30–60 分钟、十万帧级录像，稀疏抽帧会漏事件，全量载入又爆内存。
2. **微动看不见**：0.01–0.5px 级的呼吸缩放、缓动尾巴、亚像素漂移，单帧对比看不出来。
3. **小字小件看不清**：HUD 小字、徽章、按钮状态在整图缩放后糊成一团，复刻时最容易丢。

## 对应工具链
- **O(1) 流式索引**（`stream_long_video_indexer.py`，来源 motiscope / VidaForge /
  video-frames-skill / video-use）：逐帧流式扫描不载入全片；32x18 瓦片网格定位
  单瓦片微变（LOCALIZED_MICRO_CHANGE），双锚点累积检测慢速漂移（CUMULATIVE_SLOW_DRIFT）。
- **双向因果账本**（`bidirectional_context_ledger.py`，来源 HKUDS/VideoRAG /
  VideoAgent / MovieChat）：正向滚动状态 + 反向因果回填，跨 chunk 不失忆；
  顺带拟合资源/成长曲线公式（线性/指数 + R²）。
- **微差条与亚像素示波器**（`extract_micro_frame_deltas.py` + `subpixel_motion_oscilloscope.py`，
  来源 DVR-Scan / snapcn motion-quality）：变化包围盒 3x 放大条 + 10x 残差放大；
  用边缘 alpha 权重恢复 0.01px 轨迹，拟合循环周期与 cubic-bezier 速度曲线。
- **SAHI 微细节切片**（`slice_micro_detail_crops.py`，来源 uxkin/ui-from-screenshot /
  pixel-perfect-skill）：2x2 重叠象限 + HUD/竞技场/控制区 1:1 原生像素裁剪 +
  Top-8 高边缘密度微件 2x 放大，并提取占比 0.05%–2.5% 的稀有强调色。
- **视觉裁决闭环**（`visual_verdict_diff_loop.py`，来源 vibeeval/visual-verdict /
  garrytan/gstack / harness-engineering）：原图 | 复刻 | Delta-E 热力图三联并排，
  6 维打分 ≥90 才算过；不过就按热力图定位回炉。另有 rastian 的 24 点微细节清单做人工兜底。

## 本仓实测（整合时）
流式索引器在真实视频上产出 packed_timeline.md + 微能量 JSON；微差脚本截出 24 个补丁条；
示波器在 73 帧上拟合出 sharp_cubic_bezier_burst；裁决闭环对两张不同帧给出 67.86/100
判 REVISE——分数与肉眼差异一致，不是摆设。
