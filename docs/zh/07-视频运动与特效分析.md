# 07 · 视频运动与特效分析（第二版增补）

## 要解决的问题
旧版抽帧是稀疏采样（约 1fps）+ 静态图识读：挥砍弧线、缓动曲线、顿帧（Hit-Stop）、
震屏幅度、打击闪光这些「帧间信息」全部丢失。第二版（19 来源版）专门补这一层。

## 四项技术
1. **宏观→微观下钻**（Schmandarine/web-motion-skill）：先 16/24 格宏观接触表定位动作段，
   再对该段做 30/60fps 连续帧动作条逐帧看。
2. **光流 + 洋葱皮轨迹**（alirezarezvani/senior-computer-vision）：OpenCV Farneback 稠密光流
   算每像素运动矢量；8 帧半透明叠加成洋葱皮轨迹图（青=启动、金=打击、品红=收招）。
3. **自适应分档 + 音画并行**（bsisduck/video-analyzer-skill）：按运动强度分档抽帧、
   场景切分、音频瞬态峰值提取，视觉/运动/音频三个子 Agent 并行分析。
4. **时序-缓动量化**（LottieFiles/motion-design-skill + frankxai）：位移拟合贝塞尔缓动曲线，
   对照查表（打击闪光 50–70ms、顿帧 40–95ms、拾取弹跳 120–180ms easeOutBack、
   挥砍/冲刺 150–250ms cubic-bezier(0.16, 1, 0.3, 1)），并过 web-motion-auditor 5 点质量门禁。

## 两个新脚本（skill/scripts/）
| 脚本 | 输出 |
|---|---|
| `extract_motion_trails_and_vfx.py` | `action_burst_strip_*.png`（高帧率连续动作条）、`onion_skin_trail_*.png`（光流箭头洋葱皮轨迹）、`vfx_timing_report.json`（phaseCorrelate 震屏位移、顿帧帧号、闪光尖峰、拟合缓动类型） |
| `extract_audio_sfx_peaks.py` | `audio_peaks.json`（50ms RMS 包络峰值 → 音效事件对齐到时间/帧号，分 small/medium/large 档） |

依赖新增 `opencv-python-headless`（见 requirements.txt）。本仓整合时已用真实视频实测：
两脚本均正常产出（3 组动作条/轨迹图 + 特效时序 JSON；音频峰值检出多处 medium 档事件）。
