# 04 · 脚本参考（skill/scripts/，共 20 个）

## 视频分析
| 脚本 | 用途 | 基本用法 |
|---|---|---|
| `analyze_gameplay_video.py` | 一站式遥测：抽帧+接触表+HUD 方差图+场景切分+主色板 → telemetry.json | `analyze_gameplay_video.py <video> <out_dir> [--frames 16]` |
| `extract_video_frames.py` | 按 fps/起止抽帧并缩放为运行时纹理序列 | `extract_video_frames.py <video> <out_dir> [--fps N --width W]` |
| `sheet_contact.py` | 把帧目录拼成带编号的接触表，供挑帧/对图 | `sheet_contact.py <frames_dir> <out.png> [--cols 4]` |

## 美术与骨骼（Spine 链）
| 脚本 | 用途 | 基本用法 |
|---|---|---|
| `extract_sprites.py` | 从帧里裁出精灵/UI 元素，可去纯色底 | `extract_sprites.py <frame> <out> [--crop x,y,w,h --remove-bg]` |
| `chroma_key_magenta.py` | 去除 #FF00FF 品红（或自定义）键底并自动裁边 | `chroma_key_magenta.py <in> <out> [--tolerance 45 --trim]` |
| `provider_stub.py` | 图像/视频生成模型的供应商中立适配接口（品红底等约定） | 作为库导入，无独立 CLI |
| `position_parts.py` | 把拆分的身体部件 PNG 自动定位回整图，输出 layout.json | `position_parts.py --reference <img> --parts <dir>` |
| `build_spine_json.py` | 按 layout 生成 Spine 4.2 skeleton.json（骨骼层级+6 动画预设） | `build_spine_json.py --config layout.json [--output skeleton.json]` |
| `make_atlas.py` | 把部件 PNG 打包成 Spine .atlas + 图集 PNG | `make_atlas.py --parts <dir> [--name skeleton]` |
| `generate_spine_player.py` | 生成可独立打开的 HTML5 Canvas 骨骼动画播放器 | `generate_spine_player.py --skeleton skeleton.json` |

## 视频运动与特效（第二版新增，需 opencv）

|---|---|---|

## 图片反推玩法（第三版新增，部分需 opencv）
| 脚本 | 用途 | 基本用法 |
|---|---|---|
| `infer_gameplay_from_image.py` | 从一张截图反推玩法：输出 recon_gameplay_spec.json + features.csv 特性矩阵 | `infer_gameplay_from_image.py <image> <out_dir>` |
