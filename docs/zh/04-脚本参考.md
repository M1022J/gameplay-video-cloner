第四版（2026-10-25）去重后只剩 12 个全能脚本，零重叠。括号内是被合并掉的旧脚本。

## 长视频与微差（第四版新增方向）
| 脚本 | 用途 | 基本用法 |
|---|---|---|
| `stream_long_video_indexer.py` | O(1) 内存流式扫描 30–60+ 分钟长视频：32x18 瓦片微差 + 累积漂移检测，输出 packed_timeline.md + 微能量 JSON（合并 analyze_gameplay_video / extract_video_frames / sheet_contact） | `stream_long_video_indexer.py <video> <out_dir> [--stride 1]` |
| `extract_micro_frame_deltas.py` | 只截变化包围盒的 3x 放大微差条 + 10x 残差放大条 | `extract_micro_frame_deltas.py <video> <out_dir> [--start S --duration S]` |
| `subpixel_motion_oscilloscope.py` | 0.01px 亚像素质心轨迹 + 循环周期/贝塞尔速度曲线拟合 | `subpixel_motion_oscilloscope.py <video> <out.json> [--roi x,y,w,h]` |
| `bidirectional_context_ledger.py` | 双向因果账本：跨 chunk 滚动状态 + 反向因果回填 + 经济曲线拟合（init / append-chunk / export-brief） | `bidirectional_context_ledger.py init <ledger.json>` |
