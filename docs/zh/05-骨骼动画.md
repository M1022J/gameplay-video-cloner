# 05 · 2D / 3D 骨骼动画

## 2D：Spine 4.2 标准人形（16 骨）
`root → hip → torso → neck/head/hat`，双臂 `shoulder→upper-arm→lower-arm→hand`，
双腿 `upper-leg→lower-leg→foot`。6 个程序化动画预设（三次贝塞尔 [0.25, 0, 0.75, 1]）：
idle 2.0s 呼吸浮动（头部 0.1s 相位延迟做跟随）、walk 0.8s 对侧摆、run 0.5s 前倾腾空、
attack 0.6s 蓄力→打击→收招三段、jump 1.0s、wave 1.2s。
工具链：`position_parts.py → build_spine_json.py → make_atlas.py → generate_spine_player.py`，
原文与示例在 `upstream/spine-animation-ai/`。

## 两骨解析 IK（solveTwoBoneIK）
给根点、目标点与两段骨长，用余弦定理直接解出关节角——用于手臂瞄准、脚步贴地，
零依赖、Canvas 里可直接跑。公式与 JS 实现见 `HANDBOOK.md` 第 2.1 节。

## 2D 补充：Rive 网格与状态机
顶点多骨权重蒙皮（w1+w2+w3+w4=1）做披风/头发柔体；三层状态机：
0 层移动（Idle/Walk/Run 按速度混合 + 跳/落/着地）、1 层上半身动作覆盖（攻击/瞄准）、
2 层受击叠加（150ms 后仰+闪白）。原文 `upstream/rive-skills/`。

## 3D：Blender 绑骨与运行时
生产骨链 `root→pelvis→spine×3→chest→neck→head` + 四肢扭转骨；每顶点 ≤4 骨影响、
极向目标两骨 IK、烘焙 NLA 后导出 .glb（+Y Up）。运行时可用 Three.js 程序化 rig
（`createProcedural3DRig`，Group 关节层级）或 `GlbAnimationController`
（AnimationMixer 0.18s 交叉淡化）。原文 `upstream/opencode-blender-rigging-animation/`、
`upstream/blender-skills/`（94 个 Blender 技能）。

## 游戏感（Juice）三件套
- 震屏：trauma² 衰减正弦偏移，只加在渲染 `ctx.translate`，绝不动物理坐标
- 顿帧：hit_stop 用真实时间（performance.now），三档 small/medium/large 45–95ms
- 挤压拉伸：easeOutBack 体积守恒缩放；合并类玩法 1.3x→1.0x 回弹
数值基线（重力/反弹/摩擦/土狼时间等）按品类查 `HANDBOOK.md` 第 3.3 节。
